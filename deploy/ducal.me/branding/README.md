# Branding — vitrine `ducal.me`

Overlay visuel autonome. Aucun fichier du cœur de Homepage n'est modifié.

## Activation

Monter `custom.css` dans `/app/config/custom.css`, puis le référencer dans
`settings.yaml` :

```yaml
customCSS: custom.css
```

## Choix

- Accent **teal** (routage) + neutres **ardoise**, cohérent avec l'audit de la vitrine.
- Signaux hors-ligne en **ambre**, lisibles en thème sombre.
- **Focus clavier visible** (accessibilité) — un garde-fou, pas une décoration.
